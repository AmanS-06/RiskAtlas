# context/

Working notes for people (and tools) picking up the UI remake. Not documentation for the submission; the submission
docs live in `docs/`.

| File | What it holds |
|---|---|
| `PROJECT_CONTEXT.md` | Running state of the project. Updated with every commit. Read this first. |
| `TRACK_A_BRIEF.md` | What the organisers require and how it is scored (summary of the Track A problem statement). |
| `ML_NOTES.md` | What the models do and what the UI must respect (limits, latencies, counter-intuitive drivers). |
| `UI_REMAKE.md` | Decisions, constraints, plan and open items for the UI remake. |
