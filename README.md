# RiskAtlas

Interactive 3D cardiovascular risk visualization and prediction.

**Track A — Multimodal AI Hackathon 2026** (KamandPrompt, IIT Mandi)

RiskAtlas predicts overall coronary artery disease (CAD) status and per-vessel stenosis
probability for the LAD, LCX and RCA from clinical, ECG, laboratory and echocardiographic
features, then maps those predictions onto an interactive 3D heart model with an
explainability dashboard alongside.

> **Clinical safety disclaimer.** RiskAtlas is for decision support and educational
> purposes only. It is not a substitute for formal diagnostic imaging or clinical
> judgement, and it must not be used to make patient care decisions.

## Repository layout

```text
config/      single source of truth: features, target->mesh manifest, risk bands
common/      shared helpers: paths, config loading, canonical names, seed
data/        raw (gitignored), processed, external validation set
pipeline/    training scripts: preprocess, train, evaluate, explain, counterfactual
models/      trained model files + metadata
reports/     generated metrics and figures (never hand-typed numbers)
api/         FastAPI backend: /predict and /meta
web/         Vite + React + TypeScript frontend (viewer, dashboard)
cv/          clinical report reader (OCR -> fields)
slm/         optional natural-language layer
notebooks/   exploration only
docs/        documentation, architecture diagram, leakage audit
```

## Contributing

Read the team standard in `docs/` before your first commit. In short:

- Config is the single source of truth — no hardcoded feature names, vessel names,
  colours or thresholds.
- Never use `LAD`, `LCX`, `RCA` or `Cath` as model input features (target leakage).
- `git pull` before you start and before you push. Never force-push `main`.
- Every metric in the docs comes from `reports/`, generated by a script.
