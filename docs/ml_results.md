## 13. Original split-sample check (superseded)

The first design held out 61 patients, locked, and scored them once with the first model set (holdout opened for 1 model set(s)). Those results are kept unchanged in `reports/archive/split_sample_v1/`. With about two dozen events per vessel, a single small holdout has very wide intervals and depends on which patients fall in it, so the project moved to developing on all patients with cross-validated performance (Steyerberg, J Clin Epidemiol 2018, recommends against random splitting in small samples). The change was made after this result was seen, which is why it is reported here in full.

## 14. Model experiments

Approaches compared on the original 242-patient development set, all on identical repeated cross-validation folds, before the final design was chosen. TabPFN v2 is a pretrained foundation model for small tabular data (Hollmann et al., Nature 2025). It was not adopted: its gains are within noise, it is worse on RCA, and at several seconds per prediction on a CPU it would break real-time interaction in the 3D viewer. That a state-of-the-art model barely moves the result suggests the ceiling is the information in the features, not the model.
